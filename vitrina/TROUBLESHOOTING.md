# 🔧 Решение проблем с регистрацией

## Проблема: "Ошибка регистрации"

### Возможные причины:

1. **Telegram бот не настроен или пользователь не писал боту**
   - Решение: Пользователь должен сначала написать боту `/start` в Telegram
   - Проверьте токен бота в `.env` файле

2. **Пользователь уже существует**
   - Решение: Используйте другой ФИО или Telegram username

3. **Backend не запущен**
   - Решение: Проверьте `pm2 status` и запустите backend

4. **Проблемы с базой данных**
   - Решение: Проверьте логи `pm2 logs vitrina-backend`

## Проверка на сервере

### 1. Проверить логи backend

```bash
pm2 logs vitrina-backend --lines 50
```

Ищите ошибки типа:
- "Ошибка регистрации"
- "Не удалось отправить код в Telegram"
- "Prisma error"

### 2. Проверить Telegram бота

```bash
# Проверить токен в .env
cd /var/www/vitrina/backend
grep TG_BOT_TOKEN .env

# Проверить, запущен ли бот (он запускается вместе с backend)
pm2 logs vitrina-backend | grep telegram
```

### 3. Проверить базу данных

```bash
cd /var/www/vitrina/backend
npx prisma studio
# Откроется веб-интерфейс для просмотра БД
```

### 4. Проверить API напрямую

```bash
# Проверить health endpoint
curl http://localhost:3000/api/health

# Попробовать регистрацию через curl
curl -X POST http://localhost:3000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"fio":"Test User","password":"test123","telegram_username":"testuser"}'
```

## Частые ошибки и решения

### "Не удалось отправить код в Telegram"

**Причина:** Пользователь не писал боту `/start` или неправильный username

**Решение:**
1. Пользователь должен написать боту `/start` в Telegram
2. Убедитесь, что username указан без `@`
3. Проверьте токен бота в `.env`

### "Пользователь уже существует"

**Причина:** Пользователь с таким ФИО или Telegram уже зарегистрирован

**Решение:** Используйте другой ФИО или Telegram username

### "Ошибка сервера"

**Причина:** Проблема с базой данных или кодом

**Решение:**
1. Проверьте логи: `pm2 logs vitrina-backend`
2. Проверьте БД: `npx prisma studio`
3. Перезапустите backend: `pm2 restart vitrina-backend`
