# 🔧 Исправление ошибки 502 Bad Gateway

## Проблема: 502 Bad Gateway при входе

Nginx не может подключиться к backend на порту 3000.

## Быстрая диагностика

### 1. Проверить Backend

```bash
pm2 status
```

**Если backend не запущен:**
```bash
cd /var/www/vitrina/backend
pm2 start src/app.js --name vitrina-backend
pm2 save
```

### 2. Проверить, что backend слушает на порту 3000

```bash
sudo netstat -tulpn | grep 3000
```

Должно быть:
```
tcp  0.0.0.0:3000  LISTEN  node
```

### 3. Проверить доступность backend

```bash
curl http://localhost:3000/api/health
# Должно вернуть: {"status":"ok"}
```

### 4. Проверить конфигурацию Nginx

```bash
sudo cat /etc/nginx/sites-available/vitrina | grep -A 10 "location /api"
```

Должно быть:
```nginx
location /api/ {
    proxy_pass http://localhost:3000;
    ...
}
```

## Полное исправление

### Шаг 1: Запустить Backend

```bash
cd /var/www/vitrina/backend

# Проверить .env
cat .env | grep PORT

# Запустить через PM2
pm2 delete vitrina-backend 2>/dev/null || true
pm2 start src/app.js --name vitrina-backend
pm2 save

# Проверить логи
pm2 logs vitrina-backend --lines 20
```

### Шаг 2: Проверить конфигурацию Nginx

```bash
sudo nano /etc/nginx/sites-available/vitrina
```

Убедитесь, что блок `/api/` правильный:

```nginx
location /api/ {
    proxy_pass http://localhost:3000;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection 'upgrade';
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_cache_bypass $http_upgrade;
}
```

**Важно:** `proxy_pass` должен быть `http://localhost:3000` (без слэша в конце для `/api/`)

### Шаг 3: Проверить и перезапустить

```bash
# Проверить конфигурацию
sudo nginx -t

# Перезапустить Nginx
sudo systemctl restart nginx

# Проверить логи Nginx
sudo tail -f /var/log/nginx/error.log
```

### Шаг 4: Проверить работу

```bash
# Backend напрямую
curl http://localhost:3000/api/health

# Через Nginx
curl http://localhost/api/health
curl https://altdi.ru/api/health
```

## Частые причины 502

### 1. Backend не запущен

```bash
pm2 status
# Если пусто - запустить
pm2 start src/app.js --name vitrina-backend
```

### 2. Backend слушает только на 127.0.0.1

Проверьте в `backend/src/app.js`:
```javascript
app.listen(PORT, '0.0.0.0', () => {
  console.log(`Сервер запущен на порту ${PORT}`);
});
```

Или просто:
```javascript
app.listen(PORT, () => {
  console.log(`Сервер запущен на порту ${PORT}`);
});
```

### 3. Неправильный proxy_pass в Nginx

Должно быть:
```nginx
proxy_pass http://localhost:3000;
```

НЕ должно быть:
```nginx
proxy_pass http://localhost:3000/;  # Слэш в конце для /api/ не нужен
```

### 4. Проблемы с правами

```bash
# Проверить, что backend может слушать на порту 3000
sudo netstat -tulpn | grep 3000
```

## Быстрое исправление

```bash
# 1. Запустить backend
cd /var/www/vitrina/backend
pm2 restart vitrina-backend || pm2 start src/app.js --name vitrina-backend
pm2 save

# 2. Проверить порт
sudo netstat -tulpn | grep 3000

# 3. Проверить доступность
curl http://localhost:3000/api/health

# 4. Перезапустить Nginx
sudo systemctl restart nginx

# 5. Проверить логи
pm2 logs vitrina-backend --lines 10
sudo tail -f /var/log/nginx/error.log
```
