# 🌐 Настройка DNS для домена altdi.ru

## Общая информация

- **Домен**: altdi.ru
- **IP сервера**: 188.215.31.206

## Где настраивать DNS

DNS настраивается в панели управления доменом (где вы купили домен altdi.ru).

Обычно это:
- **REG.RU** - https://www.reg.ru
- **Timeweb** - https://timeweb.com
- **Namecheap** - https://www.namecheap.com
- **GoDaddy** - https://www.godaddy.com
- Или другой регистратор доменов

## Необходимые DNS записи

### 1. A запись для основного домена

```
Тип: A
Имя: @ (или пустое, или altdi.ru)
Значение: 188.215.31.206
TTL: 3600 (или Auto)
```

### 2. A запись для www поддомена

```
Тип: A
Имя: www
Значение: 188.215.31.206
TTL: 3600 (или Auto)
```

## Пошаговая инструкция

### Шаг 1: Войти в панель управления доменом

1. Откройте сайт вашего регистратора доменов
2. Войдите в личный кабинет
3. Найдите раздел "Мои домены" или "Управление доменами"
4. Выберите домен **altdi.ru**

### Шаг 2: Найти раздел DNS

Обычно это называется:
- "DNS записи"
- "Управление DNS"
- "DNS зона"
- "Настройки DNS"

### Шаг 3: Добавить A записи

#### Запись 1 (основной домен):

Нажмите "Добавить запись" или "Создать запись" и заполните:

- **Тип записи**: A
- **Имя/Хост**: `@` (или оставьте пустым, или `altdi.ru`)
- **Значение/IP**: `188.215.31.206`
- **TTL**: `3600` (или Auto)

#### Запись 2 (www поддомен):

- **Тип записи**: A
- **Имя/Хост**: `www`
- **Значение/IP**: `188.215.31.206`
- **TTL**: `3600` (или Auto)

### Шаг 4: Сохранить изменения

Нажмите "Сохранить" или "Применить изменения"

## Альтернатива: CNAME для www

Вместо A записи для www можно использовать CNAME:

```
Тип: CNAME
Имя: www
Значение: altdi.ru
TTL: 3600
```

## Проверка DNS

После добавления записей подождите 5-30 минут для распространения DNS, затем проверьте:

### Онлайн сервисы:

1. **https://dnschecker.org/**
   - Введите: `altdi.ru`
   - Выберите тип: `A`
   - Нажмите "Search"
   - Должно показать `188.215.31.206` во всех локациях

2. **https://www.whatsmydns.net/**
   - Введите: `altdi.ru`
   - Выберите тип: `A`
   - Проверьте разные локации

### С командной строки:

```bash
# Проверка A записи
dig altdi.ru +short
# Должно вернуть: 188.215.31.206

# Проверка www
dig www.altdi.ru +short
# Должно вернуть: 188.215.31.206

# Подробная проверка
dig altdi.ru A
```

## Примеры для разных регистраторов

### REG.RU

1. Войдите в личный кабинет: https://www.reg.ru
2. Перейдите: "Мои домены" → "altdi.ru" → "DNS-серверы и зона"
3. Добавьте записи:
   - Тип: A, Поддомен: @, IP: 188.215.31.206
   - Тип: A, Поддомен: www, IP: 188.215.31.206

### Timeweb

1. Войдите в панель: https://timeweb.com
2. Перейдите: "Домены" → "altdi.ru" → "DNS-записи"
3. Добавьте A записи

### Namecheap

1. Войдите: https://www.namecheap.com
2. Перейдите: "Domain List" → "altdi.ru" → "Advanced DNS"
3. Добавьте A записи в "Host Records"

## Важно!

1. **Распространение DNS** занимает 5-30 минут (иногда до 48 часов)
2. **TTL** - время жизни записи, обычно 3600 секунд (1 час)
3. **Проверяйте** через онлайн сервисы после настройки

## После настройки DNS

Когда DNS записи настроены и распространились:

1. Сайт будет доступен по адресу: `https://altdi.ru`
2. Проверьте доступность: `curl -I https://altdi.ru`
3. Должен вернуться HTTP 200 OK

## Решение проблем

### DNS не обновляется

- Подождите до 48 часов
- Проверьте правильность IP адреса
- Убедитесь, что записи сохранены

### Сайт не открывается после настройки DNS

- Проверьте, что сервер работает: `pm2 status`
- Проверьте Nginx: `sudo systemctl status nginx`
- Проверьте firewall в панели провайдера
